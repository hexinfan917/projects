## 核心判断逻辑

```tsx
const hasProfile = userInfo.real_name || userInfo.phone || userInfo.id_card

let isSelf = false
if (form.id_card && userInfo.id_card) {
  // 资料有身份证：通过身份证号匹配判断
  isSelf = form.id_card === userInfo.id_card
} else if (!hasProfile && !form.id) {
  // 资料完全空白 + 新建：第一个出行人默认认为是本人
  isSelf = existList.length === 0
}

// 新建问同步：isSelf && !hasProfile
// 编辑问同步：isSelf && changed
```

## 一、环境准备

### 1.1 开发者工具中清除缓存
```js
Taro.clearStorageSync()
wx.reLaunch({ url: '/pages/index/index' })
```

### 1.2 准备测试数据
以下测试可用**同一个账号**完成，通过清除缓存 + 操作来改变状态。

| 状态 | 说明 | 如何进入 |
|------|------|---------|
| 状态A | 资料完全空白 | 新注册账号 / 清除缓存后登录 |
| 状态B | 资料有完整信息 | 状态A → 同步一次后 |
| 状态C | 资料有姓名+手机，无身份证 | 需要后端手动改数据 |

**快速切换状态A的方法**：开发者工具 Console 执行：
```js
Taro.removeStorageSync('user_info')
Taro.removeStorageSync('access_token')
// 然后重新登录
```

## 二、新建出行人测试用例

### TC-01 【资料空白 + 第一个出行人 → 问同步】⭐ 核心场景

**前置条件**
- 账号处于「状态A」（资料完全空白：无 real_name / phone / id_card）
- 出行人列表为空（首次添加）
- 进入「我的」→「出行人管理」→「新增出行人」

**操作步骤**
1. 姓名输入：`张三`
2. 手机号输入：`13800138000`
3. 身份证号输入：`110101199001011234`
4. 点击「保存」

**预期结果**
- ✅ 出行人保存成功，toast「保存成功」
- ✅ **弹出同步弹窗**：「是否将出行人信息同步到个人资料？」
- 点击「同步」后，`user_info` 被填充（real_name / phone / id_card 均有值）
- 自动返回列表页

**验证方法**
```js
Taro.getStorageSync('user_info')
// 应包含 real_name, phone, id_card
```

## 四、边界场景测试用例

### TC-11 【编辑同行人改成本人身份证 → 问同步】

**前置条件**
- 账号处于「状态B」（资料身份证：`110101199001011234`）
- 出行人列表中有同行人（如身份证 = `310101199002022345`）
- 进入该同行人的「编辑」页面

**操作步骤**
1. 将身份证号修改为：`110101199001011234`（与资料一致）
2. 确保姓名与资料不同（如改为「测试名」）
3. 点击「保存」

**预期结果**
- ✅ 保存成功
- ✅ **弹出同步弹窗**
- **原因**：编辑后 `isSelf = true`（身份证匹配）且信息有变化

---

### TC-12 【编辑本人改成同行人身份证 → 不问同步】

**前置条件**
- 账号处于「状态B」（资料身份证：`110101199001011234`）
- 出行人列表中有本人出行人
- 进入本人出行人的「编辑」页面

**操作步骤**
1. 将身份证号修改为：`310101199002022345`（与资料不一致）
2. 点击「保存」

**预期结果**
- ✅ 保存成功
- ❌ **不弹出**同步弹窗
- **原因**：编辑后 `isSelf = false`（身份证不匹配）

在开发者工具中，可在保存前临时插入调试代码，查看各变量值：

```js

console.log('form.id_card:', form.id_card)
console.log('userInfo.id_card:', userInfo.id_card)
console.log('existList.length:', existList.length)
console.log('isSelf:', isSelf)
console.log('shouldAskSync (新建):', !form.id && isSelf && !(userInfo.real_name || userInfo.phone || userInfo.id_card))

```
