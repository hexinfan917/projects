# 犬格检测功能产品需求文档（PRD）

## 1. 功能概述

**犬格检测**是为宠物狗设计的性格与行为标准化测评工具，类似人类 MBTI / 性格测试。用户（主人）根据狗狗日常真实表现回答 17 道选择题，系统按模块计分并给出总分、性格分型、潜在行为隐患及饲养 / 训练建议。

该功能作为小程序核心入口之一（首页「犬格检测」），既能帮助主人了解狗狗性格，也能为平台推荐合适路线、活动分组、保险等级等提供数据支撑。

---

## 2. 目标用户与场景

| 用户 | 场景 | 价值 |
|------|------|------|
| 养狗主人 | 带狗出行前，评估狗狗是否适合某类活动 | 避免应激、冲突、意外 |
| 潜在用户 | 注册后首次使用，快速建立宠物档案 | 增强粘性，了解平台专业性 |
| 平台运营 | 根据犬格结果做路线推荐、保险定价、分组管理 | 提升服务精准度 |
| 训犬师 | 查看测评报告，后续复核验证 | 作为行为评估参考 |

---

## 3. 核心流程

```
进入犬格检测
   │
   ▼
选择要测评的宠物（从已有宠物档案中选择，或临时填写）
   │
   ▼
逐题作答（17 题，分 6 个模块）
   │
   ▼
提交并计算总分与分型
   │
   ▼
查看结果报告
   │
   ▼
可分享报告 / 重新测评 / 返回首页
```

---

## 4. 测评题目结构

共 **6 大模块、17 道试题、总分 100 分**，每题单选，按选项赋分。

### 4.1 模块划分

| 模块 | 主题 | 题号 | 满分 |
|------|------|------|------|
| 第一模块 | 陌生人耐受度（社交性格） | 1-3 | 20 分 |
| 第二模块 | 同类狗狗社交耐受度（犬际社交） | 4-6 | 18 分 |
| 第三模块 | 环境应激耐受度（胆量抗压） | 7-9 | 17 分 |
| 第四模块 | 资源占有护食行为（攻击性隐患） | 10-12 | 15 分 |
| 第五模块 | 主人服从与自控能力（随行服从） | 13-15 | 20 分 |
| 第六模块 | 分离情绪与居家行为（情绪稳定性） | 16-17 | 10 分 |

### 4.2 每道题结构

- 题干：描述一个具体场景
- 4 个选项（A/B/C/D），分别对应不同分值
- 选项按表现从优到差赋分，常见分值为 6/4/2/0、7/4/2/0、5/3/2/0 等

### 4.3 题目内容（摘要）

**第一模块：陌生人耐受度**
1. 家中来访陌生客人，狗狗第一反应
2. 陌生人主动伸手，缓慢伸向狗狗头部
3. 陌生人从主人手中短暂接过牵引绳，牵走狗狗 3 米

**第二模块：同类狗狗社交耐受度**
4. 户外遇到体型相近、情绪平稳的陌生狗狗
5. 遇到体型远大于自己的陌生狗狗
6. 和熟悉玩伴狗狗玩耍被打断

**第三模块：环境应激耐受度**
7. 突发异响（关门巨响、塑料袋风声、路人咳嗽、鞭炮声）
8. 陌生嘈杂环境（商场、寺庙、人流量大街道、香火浓重区域）
9. 地面陌生物体（雨伞、滑板、倒地杂物、反光物品）

**第四模块：资源占有护食行为**
10. 进食时主人伸手靠近食盆、拿走食物
11. 玩耍玩具时，主人强行拿走玩具
12. 休息睡觉时，主人触碰狗狗爪子、肚子、耳朵

**第五模块：主人服从与自控能力**
13. 牵引绳随行（户外平地，无特殊诱惑）
14. 主人原地静止站立 5 分钟，狗狗无指令等待
15. 户外看到零食、小动物、落叶等诱惑物

**第六模块：分离情绪与居家行为**
16. 主人短暂离开视线 5 分钟（关门单独留在家中）
17. 日常居家独处（主人在家不互动）

## 5. 计分与评级规则

### 5.1 计分规则

- 每题选择一个选项，累加得总分
- 各模块单独计分，用于生成模块雷达图 / 短板分析
- 附加补充测评（寺庙出行专项）不计入总分，单独展示

### 5.2 总分评级

| 等级 | 分数段 | 性格分型 | 标签 |
|------|--------|----------|------|
| S 级 | 85-100 分 | 稳定包容型 | 天使性格 |
| A 级 | 70-84 分 | 温和谨慎型 | 乖巧性格 |
| B 级 | 50-69 分 | 冲动敏感型 | 问题萌芽性格 |
| C 级 | 0-49 分 | 焦虑攻击型 | 高危性格 |

### 5.3 结果解读维度

每份报告至少包含：
- **总分与等级**：分数 + S/A/B/C 等级
- **性格分型**：一句话概括性格
- **性格详情**：社交、胆量、服从、情绪稳定等维度分析
- **适配场景**：适合参加什么类型的活动 / 路线
- **潜在隐患**：需要重点关注的行为问题
- **训练建议**：针对性的家庭纠正方案
- **短板模块**：得分最低的 1-2 个模块重点提示

## 6. 结果报告设计

### 6.1 报告页结构

1. **顶部视觉区**
   - 宠物头像、名字
   - 总分大数字 + 等级徽章
   - 测评日期

2. **性格分型卡**
   - 等级名称：如「S 级 · 天使性格」
   - 一句话性格描述

3. **能力雷达图**
   - 6 大模块得分可视化
   - 直观展示狗狗强项和短板

4. **详细解读**
   - 性格特点
   - 适配场景
   - 潜在隐患
   - 训练建议

5. **附加测评结果（如有）**
   - 寺庙出行专项：香火味、钟声反应等

6. **操作区**
   - 重新测评
   - 分享报告
   - 返回首页

### 6.2 分享传播

- 生成分享卡片（canvas 绘制）
- 分享标题示例：「我家 xxx 是 S 级天使性格，你家狗子是什么型？」
- 分享图片为报告摘要图

## 8. 数据模型

### 8.1 测评题目配置表 `dog_personality_questions`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| module | varchar | 模块名称 |
| module_order | int | 模块排序 |
| question_order | int | 题号 |
| title | varchar | 题干 |
| options | json | 选项数组，每项含 label、score |
| max_score | int | 本题满分 |
| is_active | tinyint | 是否启用 |

### 8.2 测评记录表 `dog_personality_results`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| user_id | int | 主人用户 ID |
| pet_id | int | 宠物档案 ID（可选） |
| pet_name | varchar | 宠物名字（临时测评时保存） |
| answers | json | 每题所选选项及得分 |
| total_score | int | 总分 |
| level | varchar | S/A/B/C |
| level_label | varchar | 天使性格 / 乖巧性格 等 |
| module_scores | json | 各模块得分 |
| report_data | json | 完整报告数据（用于回显） |
| created_at | datetime | 测评时间 |

### 8.3 结果分型配置表 `dog_personality_levels`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| level | varchar | S/A/B/C |
| min_score | int | 分数下限 |
| max_score | int | 分数上限 |
| name | varchar | 分型名称 |
| description | text | 性格描述 |
| fit | text | 适配场景 |
| risk | text | 潜在隐患 |
| suggestion | text | 训练建议 |

## 9. 管理后台需求

### 9.1 题目管理

- 列表展示所有题目
- 新增 / 编辑 / 禁用题目
- 调整模块和题号排序
- 编辑题干、选项文案、分值

### 9.2 分型管理

- 配置 S/A/B/C 各等级的分数段
- 编辑各等级性格描述、适配、隐患、建议文案

### 9.3 测评记录

- 查看用户测评记录列表
- 查看单份报告详情
- 可按用户、宠物、等级、时间筛选

---

## 10. 非功能需求

- **准确性**：测评基于长期常态行为，不是单次偶然表现，文案中需提示用户。
- **性能**：17 题纯前端答题，提交时一次性计算，响应 < 200ms。
- **可扩展**：题目、选项、分值、分型文案均后台可配置，方便后续调整。
- **分享友好**：结果页支持生成图片分享，提升传播。
- **多端复用**：测评题目配置和分型配置后端统一，小程序、H5、管理后台共用。

---

## 11. 首期 MVP 范围建议

为快速上线，建议首期实现：
1. 小程序端：答题流程 + 结果报告展示
2. 后端：题目硬编码或简单配置表 + 计分逻辑 + 结果记录
3. 管理后台：测评记录查看（题目和分型配置可二期做）
4. 分享：结果页支持微信好友分享（分享卡片二期做）

---

## 12. 后续可扩展
