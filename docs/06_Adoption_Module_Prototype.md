| 交互 | 触发 | 结果 |

| 点击上传图片 | Tap | 唤起微信选择图片，选择后上传至OSS，返回URL |
| 点击已上传图片 | Tap | 进入图片预览模式，支持左右滑动、删除 |
| 选择城市 | Pick | 底部弹出城市选择器，选择后回填 |
| 点击发布 | Tap | 校验必填项 → 未登录跳转登录 → 调用发布接口 → 成功提示 → 跳转我的领养页 |
| 点击保存 | Tap | 将表单数据存入本地缓存（Taro.setStorageSync），提示"已保存草稿" |
| 页面加载 | onLoad | 检查本地是否有草稿，有则询问"是否恢复上次草稿？" |
| 输入手机号 | Input | 实时校验手机号格式，不合法时边框变红并提示 |
| 选择收费 | Change | 选择"收费"时金额输入框获取焦点 |

### 4.4 表单校验规则

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| 宠物名字 | 必填，1-10字 | "请输入宠物名字" |
| 性别 | 必选 | "请选择性别" |
| 年龄 | 必填，1-20字 | "请输入年龄" |
| 城市 | 必选 | "请选择所在城市" |
| 描述 | 必填，10-500字 | "描述至少需要10个字" |
| 联系电话 | 必填，11位手机号 | "请输入正确的手机号" |

| 图片 | 至少上传1张 | "请至少上传1张宠物照片" |

### 5.2 元素说明

| 元素 | 类型 | 说明 |
|------|------|------|

| 交互 | 触发 | 结果 |

| 点击下架/上架 | Tap | 切换状态，调用更新接口 |
| 点击取消收藏 | Tap | 调用取消收藏接口，卡片移除或置灰 |
| 标记已领养 | Tap | 送养人可将"已上架"状态改为"已被领养"，信息从列表消失 |
